# 🕷️ AMEVA-Crawler

> **Zero-Dependency & Pure Python** 표준 라이브러리만으로 동작하는 지능형 웹 크롤링, 실시간 변경 감지, Diff 분석 및 텔레그램 알림 데스크톱 애플리케이션

---

## 🌟 주요 기능

1. **100% 파이썬 표준 라이브러리 (Zero-Dependency)**
   - `pip` 설치가 전혀 필요 없음 (`tkinter`, `urllib`, `sqlite3`, `html.parser`, `difflib`, `threading`)
2. **SQLite3 기반 영속적 데이터 및 이력 관리**
   - 크롤링 타겟 사이트 정보, 실행 히스토리, 추출된 텍스트 및 링크, Diff 결과, 텔레그램 발송 로그 로컬 저장
3. **지능형 HTML 파싱 & Diff 분석 엔진**
   - 본문 텍스트 추출 및 정제
   - **새로 등록된 공고/게시글 링크(`<a>` 태그) 자동 식별**
   - 텍스트 라인별 추가/삭제 내용 정밀 비교 및 요약
4. **실시간 텔레그램 알림 연동**
   - 변경 감지 시 서식화된 메시지와 신규 링크 실시간 전송
   - UI에서 간편하게 Bot Token 및 Chat ID 설정
   - 대화방 자동 검색(Auto-detect Chat ID) 및 테스트 메시지 발송 지원
5. **유연한 주기 스케줄링**
   - 초 단위 간격 반복 (Interval)
   - 매일 특정 시각 (Daily: 예: `09:00` 또는 `09:00,18:00`)
   - 매주 특정 요일 (Weekly: 예: `MON,WED,FRI 09:00`)
   - 특정 시간대 작동 (Time Window: 예: `09:00-18:00/60`)
6. **파이썬 기본 내장 GUI (`tkinter`)**
   - 타겟 등록/수정/삭제/즉시 실행/활성 토글
   - 상세 이력 및 Visual Diff 뷰어
   - 실시간 시스템 & 크롤링 로그 콘솔

## 🚀 실행 방법 (Quick Start)

### 1. 실행
더블클릭으로 `run.bat`을 실행하거나 터미널에서 아래 명령을 실행합니다:
```bash
py app.py
```
*(또는 `py -3 app.py` / `python app.py`)*

### 2. 텔레그램 알림 설정
1. 앱 상단의 **[⚙️ 텔레그램 설정]** 버튼을 클릭합니다.
2. 발급받은 Telegram Bot Token과 수신할 Chat ID를 입력합니다.
   - *팁: 텔레그램 봇에게 아무 메시지나 보낸 후 `[🔍 대화방 자동 감지]` 버튼을 누르면 Chat ID가 자동으로 입력됩니다.*
3. **[📬 테스트 메시지 발송]**으로 연동을 확인한 후 **[저장]**을 누릅니다.

### 3. 모니터링 타겟 등록
- **[➕ 타겟 등록]**을 눌러 URL, Method(GET/POST), 주기 등을 설정하고 저장하면 백그라운드에서 자동으로 모니터링을 시작합니다.
