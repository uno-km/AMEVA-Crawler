# 🕷️ AMEVA-Crawler

> **Zero-Dependency & Pure Python** 표준 라이브러리만으로 동작하는 지능형 웹 크롤링, 실시간 변경 감지, Diff 분석, 텔레그램 알림 및 Windows 시스템 트레이 상주 데스크톱 애플리케이션

---

## 🌟 주요 기능

1. **100% 파이썬 표준 라이브러리 (Zero-Dependency)**
   - `pip` 설치가 전혀 필요 없음 (`tkinter`, `urllib`, `sqlite3`, `html.parser`, `difflib`, `threading`, `ctypes`)
2. **Windows 시스템 트레이(System Tray) 백그라운드 상주**
   - **X (닫기) 버튼을 눌러도 종료되지 않고 시스템 트레이로 최소화**되어 백그라운드에서 24시간 끊김 없이 크롤링 지속
   - 트레이 아이콘 우클릭 시 컨텍스트 메뉴 제공 (창 열기, 즉시 전체 크롤링, 완전 종료)
   - 웹사이트 변경 발생 시 **윈도우 시스템 알림(풍선 토스트 알림)** 동시 팝업
3. **AMEVA 공식 브랜드 CI 아이콘 탑재**
   - `assets/icon.ico` 적용 (윈도우 창, 트레이 아이콘, 바탕화면 바로가기 모두 통일)
4. **SQLite3 기반 영속적 데이터 및 이력 관리**
   - 크롤링 타겟 사이트 정보, 실행 히스토리, 추출된 텍스트 및 링크, Diff 결과, 텔레그램 발송 로그 로컬 저장
5. **지능형 HTML 파싱 & Diff 분석 엔진**
   - 본문 텍스트 추출 및 정제
   - **새로 등록된 공고/게시글 링크(`<a>` 태그) 자동 식별**
   - 텍스트 라인별 추가/삭제 내용 정밀 비교 및 요약
6. **실시간 텔레그램 알림 연동**
   - 변경 감지 시 서식화된 메시지와 신규 링크 실시간 전송
   - UI에서 간편하게 Bot Token 및 Chat ID 설정
   - 대화방 자동 검색(Auto-detect Chat ID) 및 테스트 메시지 발송 지원
7. **유연한 주기 스케줄링**
   - 초 단위 간격 반복 (Interval)
   - 매일 특정 시각 (Daily: 예: `09:00` 또는 `09:00,18:00`)
   - 매주 특정 요일 (Weekly: 예: `MON,WED,FRI 09:00`)
   - 특정 시간대 작동 (Time Window: 예: `09:00-18:00/60`)

## 🚀 실행 방법 (Quick Start)

### 1. 바탕화면 바로가기 실행
바탕화면에 생성된 **`AMEVA-Crawler` 바로가기 아이콘** 또는 **`AMEVA-Crawler.bat`**을 더블클릭하면 콘솔 창 없이 조용하게 시스템 트레이 및 GUI로 실행됩니다.

### 2. 터미널 실행
```bash
py app.py
```
*(또는 `pyw app.py` - 콘솔 없이 백그라운드 구동)*

## ⚙️ 텔레그램 알림 설정
1. 앱 상단의 **[⚙️ 텔레그램 설정]** 버튼을 클릭합니다.
2. 발급받은 Telegram Bot Token과 수신할 Chat ID를 입력합니다.
   - *팁: 텔레그램 봇에게 아무 메시지나 보낸 후 `[🔍 대화방 자동 감지]` 버튼을 누르면 Chat ID가 자동으로 입력됩니다.*
3. **[📬 테스트 메시지 발송]**으로 연동을 확인한 후 **[저장]**을 누릅니다.
