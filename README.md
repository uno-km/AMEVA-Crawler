## 🌟 개요 및 특징

**AMEVA-Crawler**는 외부 서드파티 패키지(`pip`) 설치 없이 **파이썬 100% 내장 표준 모듈**만으로 구동되는 독립형 크롤링 & 모니터링 데스크톱 솔루션입니다.

* **완전 무의존성 (Zero Dependency)**: `tkinter`, `urllib`, `sqlite3`, `html.parser`, `difflib`, `threading`, `ctypes` 등 순수 파이썬 내장 라이브러리만 사용.
* **지능형 변경 감지 엔진**: 웹사이트의 이전 데이터와 현재 데이터를 비교하여 단순 텍스트 변경뿐만 아니라 **새로 올라온 공고/게시글 링크(`<a>` 태그)**를 자동으로 식별합니다.
* **실시간 멀티 알림**: 변경 발생 시 서식화된 **텔레그램 알림 메시지** 및 **Windows 우측 하단 시스템 풍선 알림**을 동시 발송합니다.
* **Windows 시스템 트레이 상주**: 창을 닫아도 백그라운드 시스템 트레이에서 24시간 끊김 없이 작동합니다.
* **AMEVA 공식 브랜드 CI 탑재**: 통일된 Dark Space & Aqua-Cyan Universe 아이콘 디자인 적용.

## 🚀 빠른 시작 & 실행 방법

### 방법 1. 바탕화면 바로가기 실행 (가장 추천)
설치 스크립트에 의해 바탕화면에 생성된 **`AMEVA-Crawler` 바로가기 아이콘**을 더블클릭합니다.
* 콘솔 검은 창 없이 조용하게 시스템 트레이 및 GUI로 구동됩니다.
* 바탕화면 바로가기를 다시 생성하려면: `py create_desktop_shortcut.py`

### 방법 2. 원클릭 배치 파일 (`run.bat`)
프로젝트 폴더 내의 [`run.bat`](./run.bat) 파일을 더블클릭합니다.

### 방법 3. 터미널(CLI) 직접 실행
```powershell
# 일반 실행 (GUI + 콘솔 출력)
py app.py

# 백그라운드 무콘솔 실행
pyw app.py
```

* **➕ 타겟 등록**: 새 웹사이트 모니터링 타겟 추가 대화상자를 엽니다.
* **✏️ 타겟 수정**: 선택한 타겟의 URL, 주기, 요청 방식, 헤더 등을 수정합니다.
* **🗑️ 타겟 삭제**: 선택한 타겟과 관련 이력 데이터를 삭제합니다.
* **▶ 즉시 실행**: 스케줄 주기와 상관없이 선택한 타겟을 즉시 1회 크롤링합니다.
* **⏯️ 활성/정지 토글**: 모니터링을 일시 정지하거나 다시 활성화합니다.
* **📋 이력 & Diff 보기**: 타겟의 과거 크롤링 히스토리와 텍스트/신규 링크 Diff를 시각적으로 확인합니다. (목록 항목 **더블클릭**으로도 열립니다)
* **⚙️ 텔레그램 설정**: Bot Token, 수신 Chat ID, 대화방 자동 검색 및 테스트 메시지를 설정합니다.
* **🔽 트레이로 최소화**: 메인 창을 숨기고 시스템 트레이 아이콘으로 축소합니다.

## 📝 모니터링 타겟 등록 및 상세 설정 (A to Z)

**[➕ 타겟 등록]** 버튼을 클릭하면 세부 설정 모달 창이 나타납니다:

1. **타겟 명칭 (`Name`)**: 구분하기 쉬운 사이트 이름 (예: `신규 채용 공고`, `공식 서비스 공지`)
2. **요청 방식 (`Method`)**:
   * **`GET`**: 일반 웹페이지 크롤링 시 사용 (기본값)
   * **`POST`**: 로그인 세션, 검색 폼 전송, REST API JSON 호출 시 사용
     * `Content-Type`: `application/json`, `application/x-www-form-urlencoded`, `text/plain`
     * `Request Body`: POST로 전송할 페이로드 데이터 입력 (JSON 문자열 또는 폼 파라미터)
3. **대상 URL (`URL`)**: 크롤링할 전체 주소 (예: `https://example.com/notices`)
4. **커스텀 HTTP 헤더 (`Headers`)**:
   * 특정 User-Agent, Referer, Authorization Bearer 토큰, Cookie 등이 필요한 경우 JSON 형식으로 입력:
   ```json
   {
     "Authorization": "Bearer YOUR_ACCESS_TOKEN",
     "Cookie": "SESSION_ID=abc12345",
     "Referer": "https://example.com"
   }
   ```
5. **감지 모드 (`Detect Mode`)**:
   * **전체 (신규 링크 + 본문 변경)**: 텍스트 내용 변화 및 신규 발견된 링크 모두 감지 (추천)
   * **신규 링크/공고만**: 새로운 `<a>` 태그 링크가 추가되었을 때만 알림
   * **본문 텍스트만**: 텍스트 내용이 변경되었을 때만 알림
6. **정규식 필터 (`Selector Rule`)**:
   * 페이지 전체가 아니라 특정 패턴(예: 날짜, 특정 키워드가 포함된 라인)만 추려서 감지하고 싶을 때 정규식 입력 (예: `[0-9]{4}-[0-9]{2}-[0-9]{2}.*?채용`)

## ⏱️ 크롤링 주기(Scheduling) 문법 완전 정복

AMEVA-Crawler는 4가지 유연한 주기 모드를 제공합니다:

| 주기 유형 | 입력 예시 | 설명 |
| :--- | :--- | :--- |
| **간격 반복 (`interval`)** | `300` | **300초(5분)마다** 주기적으로 실행 (초 단위 숫자) |
| **간격 반복 (`interval`)** | `3600` | **1시간(3600초)마다** 주기적으로 실행 |
| **매일 특정 시각 (`daily`)** | `09:00` | 매일 **오전 9시 00분**에 1회 실행 |
| **매일 특정 시각 (`daily`)** | `09:00, 18:00` | 매일 **오전 9시와 오후 6시**, 하루 2회 실행 (쉼표 구분) |
| **매주 특정 요일 (`weekly`)** | `MON,WED,FRI 09:00` | **월, 수, 금요일 오전 9시**에 실행 |
| **매주 특정 요일 (`weekly`)** | `SAT,SUN 14:00` | **주말(토, 일) 오후 2시**에 실행 |
| **특정 시간대 작동 (`time_window`)**| `09:00-18:00/60` | **오전 9시~오후 6시 사이에만 60초(1분)마다** 동작 (업무시간 전용) |

## ✈️ 텔레그램 봇 연동 가이드 (A to Z)

### 1단계. 텔레그램 봇 생성 및 Token 발급
1. 텔레그램 앱에서 **`@BotFather`**를 검색하여 대화를 시작합니다.
2. `/newbot` 명령어를 전송합니다.
3. 봇의 이름(Name)과 고유 아이디(Username, `..._bot`으로 끝남)를 입력합니다.
4. 생성이 완료되면 발급되는 **HTTP API Token** (예: `1234567890:ABCdef...`)을 복사합니다.

### 2단계. 내 Chat ID 확인 및 자동 감지
1. 방금 만든 나의 봇 검색 후 **[시작(Start)]** 또는 `/start` 아무 메시지를 1회 보냅니다.
2. AMEVA-Crawler 상단의 **[⚙️ 텔레그램 설정]** 버튼을 누릅니다.
3. **Telegram Bot Token**란에 복사한 토큰을 붙여넣습니다.
4. 우측의 **`[🔍 대화방 자동 감지]`** 버튼을 클릭합니다.
   * 방금 봇에게 말을 건 사용자의 **Chat ID가 자동으로 입력**됩니다!

### 3단계. 연동 테스트 & 저장
1. **`[📬 테스트 메시지 발송]`** 버튼을 클릭합니다.
2. 텔레그램으로 테스트 알림이 도착하는지 확인합니다.
3. **`[저장]`**을 누르면 설정이 로컬 DB에 안전하게 보관됩니다.

### 🔔 텔레그램 알림 메시지 포맷 예시
```html
🚨 [AMEVA 크롤러] 사이트 변경 감지!

🏷️ 대상명: 주요 공지사항
🌐 URL: https://example.com/notices (GET)
⚡ 상태: HTTP 200 (142ms)

🔥 [신규 공고/링크 발견] (2건)
• 2026년 하반기 신규 서비스 오픈 안내
• 시스템 정기 점검 및 업데이트 공지

➕ [추가된 본문 텍스트] (3줄)
+ [공지] 새로운 업데이트가 배포되었습니다.
+ 적용 일시: 2026-08-18 15:00 ~

🕒 감지 시각: 2026-08-18 14:00:00
```

## 🔍 지능형 Diff 분석 & 신규 링크 감지 원리

1. **스마트 파싱**: `<script>`, `<style>`, `<noscript>`, `<svg>` 등 불필요한 태그를 완전 제거하고 의미 있는 본문 텍스트만 추출합니다.
2. **링크 정규화**: 모든 `<a>` 태그의 `href` 상대 경로를 절대 URL(`https://...`)로 변환하여 수집합니다.
3. **SHA-256 고속 해싱**: 이전 성공 크롤링 데이터의 해시와 즉시 비교하여 변경 여부를 0.1ms 내에 판별합니다.
4. **신규 링크 식별**:
   $$\text{New Links} = \text{Current Links} \setminus \text{Previous Links}$$
   이전에 없었던 새로운 채용 공고나 게시글 링크를 완벽하게 분리 추출합니다.
5. **텍스트 라인 Diff**: `difflib` 엔진을 통해 추가된 라인(`+`)과 삭제된 라인(`-`)을 요약합니다.

## 🪟 Windows 시스템 트레이 & 백그라운드 운영

* **트레이 최소화**: 메인 윈도우 우측 상단의 **`X (닫기)`** 버튼을 누르면 프로그램이 종료되지 않고 **작업표시줄 트레이 아이콘으로 자동 최소화**됩니다.
* **트레이 아이콘 조작**:
  * **마우스 좌클릭 / 더블클릭**: 메인 대시보드 창 다시 열기
  * **마우스 우클릭**:
    * `🖥️ AMEVA-Crawler 열기` : 대시보드 복원
    * `⚡ 지금 전체 크롤링` : 등록된 모든 활성 사이트 즉각 크롤링 큐 실행
    * `❌ 프로그램 완전 종료` : 프로세스 및 백그라운드 스레드 안전 종료
* **풍선 도움말 알림**: 웹사이트 변경 감지 시 윈도우 우측 하단에 시스템 토스트 알림이 뜹니다.

```text

├── tray.py                     # 순수 ctypes 기반 Windows 시스템 트레이 & 풍선 알림
├── telegram_bot.py             # 텔레그램 Bot API 통신 (메시지 발송, 자동 Chat ID 감지)
├── db.py                       # SQLite3 스키마 및 CRUD 계층
├── config.py                   # 기본 설정 상수 (경로, 타임아웃 등)
├── create_icon.py              # AMEVA 브랜드 CI 멀티사이즈 ICO 생성기
├── create_desktop_shortcut.py  # 바탕화면 바로가기 생성기
├── run.bat                     # 원클릭 실행 배치 파일
├── test_crawler.py             # 단위 테스트 스위트
├── assets/
│   ├── icon.ico                # AMEVA 공식 CI 멀티사이즈 아이콘
│   └── favicon.svg             # SVG 원본
├── data/
│   └── crawler.db              # SQLite3 로컬 데이터베이스 (자동 생성 & Git 무시)
└── README.md                   # 종합 매뉴얼 (본 문서)
```

## ❓ FAQ & 트러블슈팅

### Q1. `python app.py`를 실행했는데 아무 반응 없이 `Python`만 찍히고 종료됩니다.
* **원인**: Windows의 마이크로소프트 스토어 가짜 실행 별칭(`WindowsApps\python.exe`)이 가로채기 때문입니다.
* **해결**: 파이썬 공식 윈도우 런처인 **`py app.py`** 또는 바탕화면의 **`AMEVA-Crawler` 바로가기**를 실행하세요.

### Q2. 텔레그램 알림이 오지 않습니다.
